# java-calculator-precourse

## 개요

사용자가 입력한 문자열에서 숫자를 추출하여 덧셈 결과를 계산하는 프로그램.
기본 구분자는 ,와 :이며, 사용자가 직접 커스텀 구분자를 지정할 수도 있음.
잘못된 입력 형식이 들어올 경우 IllegalArgumentException 예외를 발생시키며, 프로그램이 종료.

---

## 기능 설명

### 1. 입력 형식

- 프로그램 실행 시 사용자에게 문자열을 입력받음.
- 입력 예시는 다음과 같음.

| 입력 예시      | 설명                         |
|------------|----------------------------|
| 1,2:3      | 기본 구분자(,(콤마)와 :(콜론)로 숫자 구분 |
| //;\n1;2;3 | 커스텀 구분자(;) 사용              |
| //#\n2#3#4 | 커스텀 구분자 사용                 |

### 2. 구분자 규칙

- 기본 구분자: , 또는 :
- 커스텀 구분자: //과 \n 사이에 있는 문자가 커스텀 구분자로 지정
- 커스텀 구분자는 반드시 // 다음에 구분자를 지정하고, 이어서 \n을 포함해야 함.

### 3. 유효성 검사

- 커스텀 구분자 입력 시 \n이 존재하지 않으면 예외 발생
- 구분자로 분리된 값 중 숫자가 아닌 값이 포함될 경우 예외 발생
- 음수가 포함될 경우 예외 발생

## 코드 구조

| 메서드                            | 위치                   | 역할                      |
|--------------------------------|----------------------|-------------------------|
| input()                        | InputView            | 사용자 입력을 받음 및 형식 검증      |
| decideSeparator(String)        | CalculatorService    | 기본/커스텀 구분자 판별           |
| customSeparator(String)        | CalculatorService    | 커스텀 구분자 추출 및 본문 문자열 자르기 |
| calculate(String, String)      | CalculatorService    | 문자열을 구분자로 분리하여 숫자 합산    |
| main()                         | Application          | 프로그램 시작                 |
| printResult(CalculationResult) | OutputView           | 계산 결과 출력                |
| run()                          | CalculatorController | 프로그램 실행 흐름 제어           |
